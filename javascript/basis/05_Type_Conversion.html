05. Type Conversion

1. Introduction to Type Conversion

Meaning: Type conversion means changing a value from one data type to another.

JavaScript supports two types of conversion: Implicit and Explicit.

Example:

let value = "10";
let result = Number(value);

console.log(result);        // 10
console.log(typeof result); // number

2. Implicit Type Conversion (Type Coercion)

Meaning: JavaScript automatically converts a value from one type to another during an operation.

Example 1: String conversion

let result = "10" + 5;

console.log(result);        // "105"
console.log(typeof result); // string

Example 2: Number conversion

let result = "10" - 5;

console.log(result); // 5

Important: The + operator can perform addition or string concatenation. Other arithmetic operators usually convert numeric strings into numbers.

3. Explicit Type Conversion

Meaning: The programmer manually converts a value into another data type using built-in functions or methods.

Common functions: String(), Number(), and Boolean().

Example:

let age = "25";

let convertedAge = Number(age);

console.log(convertedAge);        // 25
console.log(typeof convertedAge); // number

4. String Conversion

Meaning: Converts a value into a string.

Syntax: String(value)

Examples:

console.log(String(100));       // "100"
console.log(String(true));      // "true"
console.log(String(null));      // "null"
console.log(String(undefined)); // "undefined"

let result = String(50);
console.log(typeof result);     // string

Important: String(value) converts the value without changing the original variable.

5. Number Conversion

Meaning: Converts a value into a number.

Syntax: Number(value)

Examples:

console.log(Number("100"));  // 100
console.log(Number("10.5")); // 10.5
console.log(Number(""));     // 0
console.log(Number(" "));    // 0
console.log(Number(true));   // 1
console.log(Number(false));  // 0
console.log(Number(null));   // 0
console.log(Number("hello"));// NaN

Important: A string containing a valid numeric value can be converted. An invalid numeric string produces NaN.

Related function: parseInt() reads an integer from the beginning of a string, while parseFloat() reads a decimal number.

console.log(parseInt("25.8"));   // 25
console.log(parseFloat("25.8")); // 25.8
console.log(parseInt("25px"));   // 25
console.log(Number("25px"));     // NaN

6. Boolean Conversion

Meaning: Converts a value into either true or false.

Syntax: Boolean(value)

Examples:

console.log(Boolean(1));        // true
console.log(Boolean(0));        // false
console.log(Boolean("hello"));  // true
console.log(Boolean(""));       // false
console.log(Boolean(null));     // false
console.log(Boolean(undefined));// false
console.log(Boolean([]));       // true
console.log(Boolean({}));       // true

Important: Boolean conversion follows JavaScript's truthy and falsy rules.

7. NaN (Not a Number)

Meaning: NaN represents an invalid or unrepresentable numeric result.

Examples:

let result = Number("hello");

console.log(result);           // NaN
console.log(typeof result);    // number
console.log(Number("abc"));    // NaN
console.log(10 / "hello");     // NaN

Important points:
1. The type of NaN is number.
2. NaN === NaN is false.
3. Use Number.isNaN(value) to check whether a value is exactly NaN.

let value = Number("abc");

console.log(Number.isNaN(value)); // true
console.log(Number.isNaN("abc")); // false

8. Truthy and Falsy Values

Meaning: In a condition, JavaScript treats values as either truthy or falsy.

Falsy values: These values behave like false in a condition.

false
0
-0
0n
""
null
undefined
NaN

Truthy values: All other values are truthy, including empty arrays and empty objects.

Boolean("hello"); // true
Boolean("0");     // true
Boolean("false"); // true
Boolean([]);      // true
Boolean({});      // true
Boolean(-1);      // true

Example using if:

let username = "";

if (username) {
    console.log("Username is available");
} else {
    console.log("Username is empty");
}

// Output: Username is empty

9. Practical Programs

1. Convert string input into a number and add 10

let input = "25";
let number = Number(input);

console.log(number + 10); // 35

2. Check whether input is a valid number

let input = "hello";
let number = Number(input);

if (Number.isNaN(number)) {
    console.log("Invalid number");
} else {
    console.log("Valid number:", number);
}

3. Check whether a value is truthy or falsy

let value = [];

if (value) {
    console.log("Truthy");
} else {
    console.log("Falsy");
}

// Output: Truthy

4. Compare implicit and explicit conversion

let a = "20";

console.log(a + 5);          // "205" (implicit string conversion)
console.log(Number(a) + 5);  // 25 (explicit number conversion)

10. Important JavaScript Points

1. Implicit conversion is also called type coercion.

2. Explicit conversion is performed manually by the programmer.

3. typeof NaN returns "number".

4. Number("") and Number(" ") return 0.

5. Number("hello") returns NaN.

6. Empty array [] and empty object {} are truthy.

7. == may perform type conversion, while === compares without type coercion.

8. Prefer explicit conversion when the expected data type needs to be clear.
