08 - JavaScript Functions

1. What is a Function?

Definition: A function is a reusable block of code designed to perform a particular task.

Why use functions? Code reusability, less repetition, better organization, easier testing and maintenance.

Important: Defining a function does not normally execute its body. We must call (invoke) it.

function greet() {
    console.log("Hello JavaScript");
}

greet(); // Function call

2. Function Declaration

Definition: A function created using the function keyword followed by a function name.

function functionName() {
    // statements
}

function greet() {
    console.log("Good morning!");
}

greet();

Key points:

1. It has a function name.

2. Function declarations are hoisted, so they can generally be called before their declaration in the same scope.

3. Useful for named, reusable tasks.

sayHello(); // Works

function sayHello() {
    console.log("Hello!");
}

3. Function Expression

Definition: A function stored inside a variable is called a function expression.

const greet = function() {
    console.log("Hello!");
};

greet();

Key points:

1. The function is assigned to a variable.

2. It may be named or anonymous.

3. A function expression assigned to const or let cannot be called before the variable is initialized.

greet(); // ReferenceError

const greet = function() {
    console.log("Hello!");
};

4. Anonymous Function

Definition: A function that does not have its own name is called an anonymous function.

const welcome = function() {
    console.log("Welcome!");
};

welcome();

Important: Anonymous functions are commonly used as function expressions and callbacks.

setTimeout(function() {
    console.log("Executed after 1 second");
}, 1000);

5. Arrow Function

Definition: A shorter way to write function expressions, introduced in ES6 (ES2015).

// Function expression
const add = function(a, b) {
    return a + b;
};

// Arrow function
const addArrow = (a, b) => {
    return a + b;
};

console.log(addArrow(10, 20)); // 30

Implicit return: For a single expression, braces and return can be omitted.

const square = n => n * n;

console.log(square(5)); // 25

Syntax rules:

1. No parameters: () => expression

2. One parameter: x => x * 2 (parentheses optional).

3. Multiple parameters: (a, b) => a + b.

4. Multiple statements require curly braces; use an explicit return if a value is needed.

const checkEven = n => {
    if (n % 2 === 0) {
        return "Even";
    }
    return "Odd";
};

Important difference: Arrow functions do not have their own this or arguments binding. They cannot be used as constructors with new.

6. Parameters and Arguments

Parameters: Variables listed in the function definition.

Arguments: Actual values passed when calling the function.

function add(a, b) { // a and b are parameters
    console.log(a + b);
}

add(10, 20); // 10 and 20 are arguments

In function greet(name), name is a parameter. In greet("Ravi"), "Ravi" is an argument.

Default parameters: A parameter can have a default value used when the argument is missing or undefined.

function greet(name = "Guest") {
    console.log("Hello " + name);
}

greet("Asha"); // Hello Asha
greet();       // Hello Guest

Important: If fewer arguments are passed, missing parameters receive undefined unless a default value is provided.

7. Return Statement

Definition: return sends a value back to the caller and ends that function's execution.

function add(a, b) {
    return a + b;
}

let result = add(10, 20);
console.log(result); // 30

return vs console.log(): return gives a value back so it can be stored, reused or passed to another function. console.log() only displays a value; it does not return that value from the function.

function getTotal(a, b) {
    return a + b;
}

let total = getTotal(5, 3);
console.log(total * 2); // 16

Important rules:

1. Statements after return in the same execution path are not executed.

2. A function without a return statement returns undefined.

3. A bare return; also returns undefined.

4. Keep the returned expression on the same line as return; a line break immediately after it triggers automatic semicolon insertion.

function getNumber() {
    return
    10;
}

console.log(getNumber()); // undefined

9. Practical Function Programs

Program 1: Add two numbers

function add(a, b) {
    return a + b;
}
console.log(add(12, 8)); // 20

Program 2: Check even or odd

function checkEvenOdd(number) {
    return number % 2 === 0 ? "Even" : "Odd";
}
console.log(checkEvenOdd(7)); // Odd

Program 3: Largest of two numbers using arrow function

const largest = (a, b) => a > b ? a : b;
console.log(largest(25, 18)); // 25

Program 4: Factorial

function factorial(n) {
    let result = 1;
    for (let i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}
console.log(factorial(5)); // 120

Program 5: Reverse a string

function reverseString(str) {
    let reversed = "";
    for (let i = str.length - 1; i >= 0; i--) {
        reversed += str[i];
    }
    return reversed;
}
console.log(reverseString("hello")); // olleh

10. Important Points & Common Mistakes

1. A function runs when it is called, or when another operation invokes it (such as a callback).

2. Use return when the caller needs a result; use console.log() to display output.

3. Parameters belong to the function definition; arguments are supplied in the function call.

4. Function declarations are hoisted; function expressions assigned to let or const cannot be called before initialization.

5. Arrow functions with curly braces need an explicit return to return a value.

6. An anonymous function has no name of its own; it can still be assigned to a variable.

7. A function without a returned value produces undefined.

12. Quick Revision

Function: Reusable block of code.

Declaration: Named function created with the function keyword.

Expression: Function assigned to a variable.

Anonymous: Function without its own name.

Arrow: Short function-expression syntax using =>.

Parameter: Variable in the function definition.

Argument: Value passed during the function call.

return: Sends a value back and ends function execution.
