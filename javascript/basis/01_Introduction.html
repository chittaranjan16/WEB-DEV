JavaScript - Introduction & Basics

1. Introduction to JavaScript

Meaning: JavaScript is a high-level programming language mainly used to make web pages interactive and dynamic.

Lightweight & Interpreted: JavaScript is commonly described as an interpreted language. Modern engines also use Just-In-Time (JIT) compilation to improve performance.

Primary Role: Adds behaviour and interactivity to web pages. It can also run outside browsers using Node.js.

Multi-Paradigm: Supports object-oriented, imperative, and declarative programming styles.

First-Class Functions: Functions can be stored in variables, passed as arguments, and returned from other functions.

2. History of JavaScript

1995: Created by Brendan Eich at Netscape.

Original names: Mocha → LiveScript → JavaScript.

Standardization: ECMAScript is the language standard maintained by Ecma International.

ES6 / ES2015: A major update that introduced features such as let, const, arrow functions, classes, and Promises.

3. Features of JavaScript

Dynamic Typing: A variable can hold values of different data types during execution.

First-Class Functions: Functions can be used like values.

Prototype-Based Inheritance: Objects can inherit properties and methods through prototypes.

Asynchronous Programming: Supports callbacks, Promises, and async/await.

Single-Threaded Execution: JavaScript code normally runs on one main thread. The event loop coordinates asynchronous work.

4. JavaScript vs Java

Important: Java and JavaScript are different programming languages. Their names are similar, but their design and runtimes are different.

5. Uses of JavaScript

Client-Side Web: Form validation, event handling, and DOM manipulation.

Server-Side: Backend applications and APIs using Node.js and frameworks such as Express.

Mobile Apps: Cross-platform applications using React Native or Ionic.

Desktop Apps: Desktop applications using Electron, for example Visual Studio Code.

6. How JavaScript Works

JavaScript Engine: Processes and executes JavaScript code and manages its memory.

Call Stack: Tracks function calls. It follows LIFO (Last In, First Out).

Heap: Memory area used for dynamically allocated data, such as objects.

Web APIs: Browser features such as timers, DOM events, and network requests.

Task Queue: Holds callbacks waiting to run, such as timer and event callbacks.

Event Loop: Coordinates queued callbacks and the call stack. It schedules a callback when the call stack is clear.

Basic Flow: Synchronous code runs on the call stack. Asynchronous browser work is handled by browser APIs. Its callback is queued and runs when the call stack is clear.

7. JavaScript Engines

A JavaScript engine is a specialized software program or interpreter that executes JavaScript code.

--

V8: Developed by Google; used by Chrome and Node.js.

SpiderMonkey: Developed by Mozilla; used by Firefox.

JavaScriptCore: Developed by Apple; used by Safari.

8. Basic JavaScript Example

// Display output
console.log("Hello, JavaScript!");

// Variables
let name = "Alex";
const age = 21;

// Check a condition
if (age >= 18) {
    console.log(name + " is an adult");
}

// Function
function add(a, b) {
    return a + b;
}

console.log(add(10, 20)); // 30

9. Important Basics to Remember

1. JavaScript is case-sensitive: name and Name are different.

2. Use let for values that may be reassigned.

3. Use const when a variable binding should not be reassigned.

4. var is the older variable declaration keyword. Understand it, but prefer let and const in modern code.

5. console.log() prints information to the browser console or Node.js terminal.

6. JavaScript statements often use semicolons. Automatic Semicolon Insertion exists, but consistent semicolon use is a good habit.
