03. Variables and Data Types

1. Variables in JavaScript

Meaning: A variable is a named container used to store data in a program.

JavaScript provides three keywords to declare variables: var, let, and const.

Syntax:

keyword variableName = value;

Example:

let studentName = "Alex";
let age = 21;

console.log(studentName);
console.log(age);

2. var

Meaning: var is the older keyword used to declare variables in JavaScript.

Reassignment: Allowed.

Redeclaration: Allowed in the same scope.

Scope: Function-scoped, or globally scoped when declared outside a function. It is not block-scoped.

Hoisting: Its declaration is hoisted and initialized with undefined.

Example:

var age = 20;
var age = 25; // Redeclaration allowed
age = 30;     // Reassignment allowed

console.log(age); // 30

Important: Avoid using var in most modern JavaScript code because its function scope and redeclaration behaviour can cause unexpected results.

3. let

Meaning: let declares a block-scoped variable.

Reassignment: Allowed.

Redeclaration: Not allowed in the same scope.

Scope: Block-scoped, meaning it is available only inside the block where it is declared.

Hoisting: It is hoisted but remains in the Temporal Dead Zone (TDZ) until its declaration is evaluated.

Example:

let marks = 70;
marks = 85; // Reassignment allowed

console.log(marks); // 85

if (true) {
    let message = "Inside block";
    console.log(message);
}

// console.log(message); // ReferenceError

4. const

Meaning: const declares a block-scoped variable whose binding cannot be reassigned.

Reassignment: Not allowed.

Redeclaration: Not allowed in the same scope.

Initialization: Must be assigned a value when declared.

Scope: Block-scoped.

Example:

const country = "India";

console.log(country);

// country = "USA"; // TypeError

Important: For objects and arrays declared with const, their contents can still be changed. Only reassignment of the variable binding is prevented.

const student = { name: "Alex" };
student.name = "Sam"; // Allowed

const numbers = [10, 20];
numbers.push(30); // Allowed

console.log(student);
console.log(numbers);

6. Variable Naming Rules

1. A variable name can contain letters, digits, underscore (_), and dollar sign ($).

2. A variable name cannot start with a digit.

3. Spaces are not allowed in variable names.

4. JavaScript variable names are case-sensitive. age and Age are different.

5. Reserved keywords such as let, class, and return cannot be used as variable names.

6. Use meaningful names and prefer camelCase for multi-word variable names.

Valid names:

let age = 21;
let studentName = "Alex";
let _count = 10;
let $price = 500;

Invalid names:

// let 1name = "Alex";   // Starts with a digit
// let student name = ""; // Contains a space
// let class = "A";       // Reserved keyword

7. Primitive Data Types

Meaning: Primitive data types store single values. Primitive values are immutable.

JavaScript has 7 primitive data types:

1. String: Represents text.

let name = "Alex";
let city = 'Bangalore';

2. Number: Represents integers and decimal numbers. It also includes NaN and Infinity.

let age = 21;
let price = 99.5;

3. BigInt: Represents integers larger than the safe range of the Number type.

let largeNumber = 12345678901234567890n;

4. Boolean: Represents true or false.

let isLoggedIn = true;

5. Undefined: A variable that has been declared but has not been assigned a value.

let result;
console.log(result); // undefined

6. Null: Represents an intentional absence of a value.

let selectedValue = null;

7. Symbol: Represents a unique value, often used as a unique object property key.

let id = Symbol("id");

8. Non-Primitive Data Types

Meaning: Non-primitive values are objects. They can hold collections of data and more complex structures.

1. Object: Stores data as key-value pairs.

let student = {
    name: "Alex",
    age: 21
};

console.log(student.name);

2. Array: Stores an ordered collection of values. Arrays are objects in JavaScript.

let marks = [80, 90, 75];

console.log(marks[0]); // 80

3. Function: A reusable block of code. Functions are callable objects in JavaScript.

function greet() {
    console.log("Hello");
}

greet();

Important: Objects, arrays, and functions are reference values. Assigning one object variable to another copies the reference, not a separate object.

9. typeof Operator

Meaning: The typeof operator returns a string indicating the type of a value.

Syntax: typeof value or typeof(value)

Examples:

console.log(typeof "Hello");     // string
console.log(typeof 100);         // number
console.log(typeof 10n);         // bigint
console.log(typeof true);        // boolean
console.log(typeof undefined);   // undefined
console.log(typeof Symbol());    // symbol
console.log(typeof {});          // object
console.log(typeof []);          // object
console.log(typeof function(){});// function
console.log(typeof null);        // object

Important points:

1. typeof null returns "object". This is a historical JavaScript behaviour, not the actual type of null.

2. typeof [] returns "object". Use Array.isArray() to check for an array.

3. typeof function() {} returns "function".

console.log(Array.isArray([10, 20])); // true
console.log(Array.isArray({}));       // false

10. Dynamic Typing

Meaning: JavaScript is dynamically typed. A variable can hold values of different data types during program execution.

The data type belongs to the value, not permanently to the variable.

Example:

let value = 100;
console.log(value, typeof value); // 100 number

value = "Hello";
console.log(value, typeof value); // Hello string

value = true;
console.log(value, typeof value); // true boolean

Important: You do not need to declare a variable's data type explicitly in JavaScript. The type is determined at runtime from the assigned value.

11. Practical Programs

1. Display variable values and types

let name = "Alex";
let age = 22;
let isStudent = true;

console.log(name, typeof name);
console.log(age, typeof age);
console.log(isStudent, typeof isStudent);

2. Demonstrate dynamic typing

let data = 50;
console.log(typeof data);

data = "Fifty";
console.log(typeof data);

data = false;
console.log(typeof data);

3. Check whether a value is an array

let value = [10, 20, 30];

if (Array.isArray(value)) {
    console.log("It is an array");
} else {
    console.log("It is not an array");
}

4. Demonstrate const with an object

const employee = {
    name: "Sam",
    salary: 30000
};

employee.salary = 35000; // Allowed
console.log(employee);

// employee = {}; // Not allowed

12. Important JavaScript Points

1. JavaScript is dynamically typed.

2. Use const by default and let when reassignment is required.

3. var is function-scoped, while let and const are block-scoped.

4. JavaScript has 7 primitive data types: String, Number, BigInt, Boolean, Undefined, Null, and Symbol.

5. Arrays and functions are also objects in JavaScript.

6. typeof null returns "object" because of a historical behaviour.

7. A const object or array can have its contents modified, but its variable binding cannot be reassigned.
