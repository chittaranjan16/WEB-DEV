04. JavaScript Operators

1. Introduction to Operators

Meaning: Operators are symbols or keywords used to perform operations on values and variables.

Operands: The values on which an operator performs an operation.

Example: In 10 + 5, + is the operator and 10 and 5 are operands.

2. Arithmetic Operators

Meaning: Used to perform mathematical calculations.

OperatorMeaningExampleResult
+Addition10 + 515
-Subtraction10 - 55
*Multiplication10 * 550
/Division10 / 52
%Remainder (modulus)10 % 31
**Exponentiation2 ** 38

Example:

let a = 10;
let b = 3;

console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.333...
console.log(a % b);  // 1
console.log(a ** b); // 1000

Important: The + operator also joins strings. For example, "10" + 5 produces "105".

3. Assignment Operators

Meaning: Used to assign a value to a variable or update its existing value.

OperatorExampleSame as

Example:

let x = 10;

x += 5;
console.log(x); // 15

x *= 2;
console.log(x); // 30

x %= 7;
console.log(x); // 2

4. Comparison Operators

Meaning: Compare two values and return a Boolean result: true or false.

OperatorMeaningExample
==Equal value (allows type conversion)5 == "5" → true
===Strict equality (value and type)5 === "5" → false
!=Not equal (allows type conversion)5 != "6" → true
!==Strict not equal5 !== "5" → true
>Greater than10 > 5 → true
<Less than10 < 5 → false
>=Greater than or equal to10 >= 10 → true
<=Less than or equal to5 <= 10 → true

Example:

console.log(10 == "10");  // true
console.log(10 === "10"); // false
console.log(10 != "10");  // false
console.log(10 !== "10"); // true

Important: Prefer === and !== to avoid unexpected type coercion.

5. Logical Operators

Meaning: Used to combine or reverse Boolean conditions.

OperatorNameMeaning
&&Logical ANDTrue only when both operands are truthy
||Logical ORTrue when at least one operand is truthy
!Logical NOTReverses the truthiness of a value

Examples:

let age = 22;
let hasID = true;

console.log(age >= 18 && hasID); // true
console.log(age < 18 || hasID);  // true
console.log(!hasID);             // false

Important: Logical operators can return one of their operands, not necessarily a Boolean value. They also use short-circuit evaluation.

6. Unary Operators

Meaning: Unary operators work with a single operand.

Common unary operators:

typeof: Returns the type of a value.

+: Converts a value to a number when possible.

-: Converts to a number and changes its sign.

!: Converts a value to Boolean and reverses it.

delete: Removes an object's property.

Examples:

let value = "25";

console.log(typeof value); // "string"
console.log(+value);       // 25
console.log(-value);       // -25
console.log(!value);       // false

let student = { name: "Alex", age: 20 };
delete student.age;
console.log(student);      // { name: "Alex" }

7. Increment and Decrement Operators

Meaning: Increment increases a numeric value by 1. Decrement decreases it by 1.

Increment: ++

Decrement: --

Pre-increment (++x): Increases the value first, then returns the updated value.

Post-increment (x++): Returns the current value first, then increases it.

Pre-decrement (--x): Decreases the value first, then returns the updated value.

Post-decrement (x--): Returns the current value first, then decreases it.

Example:

let x = 5;

console.log(++x); // 6
console.log(x);   // 6

let y = 5;

console.log(y++); // 5
console.log(y);   // 6

console.log(--y); // 5
console.log(y--); // 5
console.log(y);   // 4

Important: Prefix and postfix make a difference when the increment or decrement expression is used inside another expression.

8. Ternary Operator

Meaning: A short form of if...else that selects one of two expressions based on a condition.

Syntax:

condition ? valueIfTrue : valueIfFalse;

Example:

let age = 17;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result); // Minor

Important: It is called ternary because it has three operands: condition, true expression, and false expression. Use it for simple decisions.

9. Operator Precedence

Meaning: Operator precedence determines which operator is evaluated first when an expression contains multiple operators.

Example:

let result = 10 + 2 * 3;

console.log(result); // 16

Multiplication is performed before addition.

Using parentheses: Parentheses can change the order of evaluation.

let result = (10 + 2) * 3;

console.log(result); // 36

Common precedence order (higher to lower):

1. Parentheses: ()
2. Member access and function calls: ., ()
3. Unary operators: ! ++ -- typeof
4. Exponentiation: **
5. Multiplication, division, remainder: * / %
6. Addition and subtraction: + -
7. Relational: > < >= <=
8. Equality: == === != !==
9. Logical AND: &&
10. Logical OR: ||
11. Ternary: ?:
12. Assignment: = += -= *=

Important: Operators with the same precedence are usually evaluated according to associativity. Exponentiation and assignment are right-associative; most arithmetic operators are left-associative.

10. Practical Programs

1. Check even or odd using modulus

let number = 17;

if (number % 2 === 0) {
    console.log("Even");
} else {
    console.log("Odd");
}

2. Swap two variables using a third variable

let a = 10;
let b = 20;

let temp = a;
a = b;
b = temp;

console.log(a, b); // 20 10

3. Find the largest of two numbers using ternary

let a = 25;
let b = 40;

let largest = a > b ? a : b;
console.log(largest); // 40

4. Check eligibility using logical operators

let age = 22;
let hasID = true;

if (age >= 18 && hasID) {
    console.log("Entry allowed");
} else {
    console.log("Entry denied");
}

11. Important JavaScript Points

1. Arithmetic operators perform calculations; + can also concatenate strings.

2. Assignment operators update variable values.

3. Comparison operators return Boolean results.

4. Prefer strict equality: === and !==.

5. Logical operators use short-circuit evaluation and may return operand values.

6. Prefix increment/decrement changes the value before returning it; postfix returns the old value first.

7. Use parentheses to make complex expressions easier to understand.

8. Do not confuse = (assignment), == (loose equality), and === (strict equality).
