07 - JavaScript Loops

1. What is a Loop?

Definition: A loop is used to execute a block of code repeatedly while a condition is true or while items remain in a collection.

Why use loops? To avoid writing the same statements repeatedly and to process data efficiently.

Loop parts: Initialization → Condition → Loop body → Update.

2. for Loop

Use: When the number of repetitions is known or controlled by a counter.

for (initialization; condition; update) {
    // statements
}

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Execution order: Initialization runs once → condition is checked → body executes → update runs → condition is checked again.

Output: 1 2 3 4 5

Important: If the condition is false initially, the body will not execute.

3. while Loop

Use: When the number of repetitions is not known in advance and depends on a condition.

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Execution: Condition is checked first. If true, the body executes. Then the condition is checked again.

Important: A while loop may execute zero times. Update the condition variable to avoid an infinite loop.

4. do...while Loop

Use: When the code must execute at least once, even if the condition is initially false.

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Execution: Body executes first → condition is checked → loop repeats if true.

Important: The condition is checked after the body, so it always executes at least once.

6. Nested Loops

Definition: A loop inside another loop is called a nested loop.

Use: Pattern printing, tables, matrices and working with rows and columns.

for (let row = 1; row <= 3; row++) {
    for (let col = 1; col <= 2; col++) {
        console.log("row:", row, "column:", col);
    }
}

Key point: For each one iteration of the outer loop, the inner loop completes all its iterations.

Iteration count: If the outer loop runs 3 times and the inner loop runs 2 times per outer iteration, the inner body runs 3 × 2 = 6 times.

7. break Statement

Use: Immediately terminates the nearest enclosing loop or exits a switch statement.

for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        break;
    }
    console.log(i);
}

// Output: 1 2

Remember: In nested loops, break exits only the nearest loop, not every outer loop.

8. continue Statement

Use: Skips the remaining statements in the current iteration and moves to the next iteration.

for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        continue;
    }
    console.log(i);
}

// Output: 1 2 4 5

Difference: break stops the loop; continue skips only the current iteration.

Warning: In a while loop, make sure the update still happens when using continue, or the loop may become infinite.

9. for...of Loop

Use: To iterate over the values of iterable objects such as arrays, strings, maps and sets.

const fruits = ["Apple", "Mango", "Banana"];

for (const fruit of fruits) {
    console.log(fruit);
}

Output: Apple, Mango, Banana

Important: for...of gives each item/value directly. It does not directly provide the index.

10. for...in Loop

Use: To iterate over enumerable property keys of an object.

const student = {
    name: "Asha",
    age: 20,
    course: "JavaScript"
};

for (const key in student) {
    console.log(key, student[key]);
}

Output: name Asha, age 20, course JavaScript

Important: for...in gives property keys, not property values. Use object[key] to access a value.

Array caution: Avoid using for...in as the normal way to loop through array values. Prefer for, for...of or array methods.

12. Common Loop Programs

Program 1: Print numbers from 1 to 10

for (let i = 1; i <= 10; i++) {
    console.log(i);
}

Program 2: Sum of first N natural numbers

let n = 5;
let sum = 0;

for (let i = 1; i <= n; i++) {
    sum += i;
}
console.log(sum); // 15

Program 3: Multiplication table

let n = 7;

for (let i = 1; i <= 10; i++) {
    console.log(n + " x " + i + " = " + (n * i));
}

Program 4: Factorial of a number

let n = 5;
let factorial = 1;

for (let i = 1; i <= n; i++) {
    factorial *= i;
}
console.log(factorial); // 120

Program 5: Count digits in a number

let n = 4582;
let count = 0;

while (n > 0) {
    count++;
    n = Math.floor(n / 10);
}
console.log(count); // 4

Program 6: Reverse a number

let n = 1234;
let reverse = 0;

while (n > 0) {
    let digit = n % 10;
    reverse = reverse * 10 + digit;
    n = Math.floor(n / 10);
}
console.log(reverse); // 4321

Program 7: Check prime number

let n = 17;
let isPrime = n > 1;

for (let i = 2; i * i <= n; i++) {
    if (n % i === 0) {
        isPrime = false;
        break;
    }
}
console.log(isPrime ? "Prime" : "Not Prime");

Program 8: Print a right triangle pattern

let rows = 4;

for (let i = 1; i <= rows; i++) {
    let line = "";
    for (let j = 1; j <= i; j++) {
        line += "* ";
    }
    console.log(line);
}

13. Important Rules & Common Mistakes

1. Check the loop condition carefully to avoid off-by-one errors.

2. Ensure the loop variable changes when required; otherwise, an infinite loop may occur.

3. Use === for strict comparisons in loop conditions when appropriate.

4. break exits the nearest loop; continue skips the current iteration.

5. do...while ends with a semicolon after the condition.

6. for...of is for values; for...in is for keys.

7. In nested loops, track outer and inner variables separately.

8. Be careful with continue in while loops so the update is not skipped.

15. Quick Revision

for: Best when you control repetition with a counter.

while: Checks condition first; may run zero times.

do...while: Runs body at least once.

Nested loop: Loop inside another loop.

break: Terminates the nearest loop.

continue: Skips the current iteration.

for...of: Iterates values.

for...in: Iterates enumerable keys.
