06. Conditional Statements

1. if Statement

Meaning: Executes a block only when the condition is true.

Syntax:

if (condition) {
  // code
}

Example:

let age = 20;

if (age >= 18) {
  console.log("Eligible to vote");
}

Important: If the condition is false, the block is skipped.

2. if...else Statement

Meaning: Executes one block if true and another if false.

Syntax:

if (condition) {
  // true block
} else {
  // false block
}

Example:

let number = 7;

if (number % 2 === 0) {
  console.log("Even");
} else {
  console.log("Odd");
}

3. else if Ladder

Meaning: Checks multiple conditions in order. The first true block executes.

Syntax:

if (condition1) {
  // code
} else if (condition2) {
  // code
} else {
  // default code
}

Example:

let marks = 82;

if (marks >= 90) {
  console.log("A");
} else if (marks >= 75) {
  console.log("B");
} else if (marks >= 40) {
  console.log("Pass");
} else {
  console.log("Fail");
}

Important: Arrange conditions carefully. After the first true condition, remaining conditions are skipped.

4. Nested if

Meaning: An if statement placed inside another conditional block.

Example:

let age = 22;
let hasID = true;

if (age >= 18) {
  if (hasID) {
    console.log("Entry allowed");
  } else {
    console.log("ID required");
  }
} else {
  console.log("Under age");
}

Important: The inner condition is checked only if execution enters the outer block.

5. switch Statement

Meaning: Selects a matching case based on one expression. Useful for several fixed choices.

Syntax:

switch (expression) {
  case value1:
    // code
    break;
  case value2:
    // code
    break;
  default:
    // default code
}

Example:

let day = 2;

switch (day) {
  case 1:
    console.log("Monday");
    break;
  case 2:
    console.log("Tuesday");
    break;
  case 3:
    console.log("Wednesday");
    break;
  default:
    console.log("Invalid day");
}

Important points:
1. break exits the switch and prevents fall-through.
2. Without break, execution continues into the next case.
3. default runs if no case matches; it is optional.
4. Case matching uses strict comparison (===).

6. Ternary (Conditional) Operator

Meaning: Short form of a simple if...else. It returns one of two expressions.

Syntax:

condition ? valueIfTrue : valueIfFalse;

Example:

let age = 17;
let result = age >= 18 ? "Adult" : "Minor";

console.log(result); // Minor

Important: Called ternary because it has three operands: condition, true expression, and false expression. Use it for simple choices.

7. Practical Programs

1. Positive, negative, or zero

let num = -5;

if (num > 0) {
  console.log("Positive");
} else if (num < 0) {
  console.log("Negative");
} else {
  console.log("Zero");
}

2. Largest of two numbers

let a = 25;
let b = 40;

if (a > b) {
  console.log(a + " is greater");
} else if (b > a) {
  console.log(b + " is greater");
} else {
  console.log("Both are equal");
}

3. Largest of three numbers

let a = 10, b = 25, c = 15;

if (a >= b && a >= c) {
  console.log("A is largest");
} else if (b >= a && b >= c) {
  console.log("B is largest");
} else {
  console.log("C is largest");
}

4. Leap year

let year = 2024;

if (year % 400 === 0 || (year % 4 === 0 && year % 100 !== 0)) {
  console.log("Leap year");
} else {
  console.log("Not a leap year");
}

5. Calculator using switch

let a = 12, b = 4;
let operator = "*";

switch (operator) {
  case "+": console.log(a + b); break;
  case "-": console.log(a - b); break;
  case "*": console.log(a * b); break;
  case "/": console.log(b !== 0 ? a / b : "Cannot divide by zero"); break;
  default: console.log("Invalid operator");
}

6. Grade calculator

let marks = 76;

if (marks >= 90) {
  console.log("Grade A");
} else if (marks >= 75) {
  console.log("Grade B");
} else if (marks >= 60) {
  console.log("Grade C");
} else if (marks >= 40) {
  console.log("Grade D");
} else {
  console.log("Fail");
}

8. Important JavaScript Points

1. Conditions are evaluated as truthy or falsy values.

2. Falsy values: false, 0, -0, 0n, "", null, undefined, and NaN.

3. Empty arrays [] and empty objects {} are truthy in JavaScript.

4. Prefer === and !== for strict comparisons.

5. Use braces {} for conditional blocks, even for a single statement.

6. In an if...else if ladder, only the first matching block executes.

7. In a switch, use break to avoid unwanted fall-through.
