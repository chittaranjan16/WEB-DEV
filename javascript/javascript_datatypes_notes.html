JavaScript Data Types

Definition: A data type describes the kind of value a variable stores. JavaScript is dynamically typed, so a variable can hold values of different types at different times.

1. Types of Data Types

JavaScript data types are commonly grouped into two categories:

  • Primitive types: Number, String, Boolean, Undefined, Null, BigInt, Symbol.
  • Non-primitive/reference type: Objects. Arrays and functions are also objects or object-like values in JavaScript.

2. Your Original Examples

let n = 10;
            console.log(n, typeof n);       // 10 "number"

            let str = "hello";
            console.log(str, typeof str);   // hello "string"

            let str1 = true;
            console.log(str1, typeof str1); // true "boolean"

            let str2;
            console.log(str2, typeof str2); // undefined "undefined"

            let str3 = null;
            console.log(str3, typeof str3); // null "object"

            let str4 = 123n;
            console.log(str4, typeof str4); // 123n "bigint"
Naming tip: str1 contains a Boolean, not a string. Use meaningful names such as isActive for Boolean values.

3. Primitive Data Types

3.1 Number

Used for integers and decimal numbers. JavaScript's regular number type also includes special values such as NaN and Infinity.

let age = 21;
let price = 99.50;
let result = 10 / 0;

console.log(typeof age);    // "number"
console.log(typeof price);  // "number"
console.log(result);        // Infinity
console.log(typeof NaN);    // "number"

3.2 String

Used to store text. Strings can use single quotes, double quotes, or backticks.

let firstName = "Ravi";
let city = 'Bengaluru';
let message = `Hello, ${firstName}!`;

console.log(typeof firstName); // "string"
console.log(message);          // Hello, Ravi!

Backticks allow template literals, including interpolation with ${...}.

3.3 Boolean

Represents either true or false. Often used in conditions and comparisons.

let isLoggedIn = true;
let hasPermission = false;

console.log(typeof isLoggedIn); // "boolean"
console.log(10 > 5);             // true

3.4 Undefined

A variable declared without an assigned value has the value undefined.

let score;

console.log(score);         // undefined
console.log(typeof score);  // "undefined"

JavaScript can also return undefined when a property or function result is absent.

3.5 Null

null represents an intentional absence of a value.

let selectedUser = null;

console.log(selectedUser);        // null
console.log(typeof selectedUser); // "object"
Important: typeof null returns "object" because of a historical JavaScript quirk. It does not mean that null is an object. Check it with value === null.

3.6 BigInt

Used for integers larger than the safe range of the regular Number type. Add n to an integer literal.

let bigNumber = 123456789012345678901234567890n;

console.log(bigNumber);
console.log(typeof bigNumber); // "bigint"
Do not mix BigInt and Number in arithmetic directly. Convert deliberately when appropriate. 
// 10n + 5n; // Works: 15n
// 10n + 5;  // TypeError

3.7 Symbol

A Symbol creates a unique primitive value, often used as a unique object property key.

let id1 = Symbol("id");
let id2 = Symbol("id");

console.log(id1 === id2); // false
console.log(typeof id1);  // "symbol"

4. Non-Primitive / Reference Type: Object

Objects can group related data using key-value pairs. Arrays and functions are also objects in JavaScript, although functions have their own typeof result.

Object

let student = {
    name: "Ravi",
    age: 21
};

console.log(student.name);       // Ravi
console.log(typeof student);     // "object"

Array

let marks = [80, 90, 75];

console.log(marks[0]);        // 80
console.log(typeof marks);     // "object"
console.log(Array.isArray(marks)); // true

Use Array.isArray() to reliably check whether a value is an array.

Function

function greet() {
    console.log("Hello!");
}

greet();
console.log(typeof greet); // "function"

6. Dynamic Typing

In JavaScript, a variable declared with let can be reassigned a value of a different type.

let value = 100;
console.log(typeof value); // "number"

value = "one hundred";
console.log(typeof value); // "string"

value = true;
console.log(typeof value); // "boolean"
The variable does not have one fixed type. The value currently stored determines its type.

7. Common Mistakes and Important Rules

  • typeof "25" returns "string", while typeof 25 returns "number".
  • typeof null returns "object" due to a historical quirk.
  • typeof [] returns "object"; use Array.isArray([]) to test arrays.
  • undefined often means a value has not been assigned; null usually means an intentional empty value.
  • JavaScript is case-sensitive: true is valid, but True is not the Boolean literal.
  • typeof returns a string, for example "number" with quotation marks.
  • Use === for strict comparison when you do not want automatic type conversion.
