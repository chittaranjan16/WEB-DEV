CSS Position Properties

1. Static Position

Static is the default position. The top, left, right and bottom properties do not move a static element.

Static

2. Relative Position

Relative moves the element from its original position. Its original space remains reserved.

Relative

3. Absolute Position

The child is positioned relative to its nearest positioned ancestor. Here, the parent uses position: relative.

Parent (Relative)
Absolute Child

4. Fixed Position

Look at the bottom-right corner. The red box stays fixed relative to the browser viewport while you scroll.

Fixed
