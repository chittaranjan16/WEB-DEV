CSS Background Properties

CSS background properties control the background color, images, image size, position, repetition, gradients, and other visual effects of an element.

1. Background Color

background-color sets the background color of an element.

Background Color

2. Background Image

background-image displays an image behind an element's content.

Background Image

3. Background Repeat

repeat

Repeats the image horizontally and vertically.

Repeat

no-repeat

Displays the background image only once.

No Repeat

repeat-x

Repeats the image horizontally.

Repeat X

repeat-y

Repeats the image vertically.

Repeat Y

4. Background Size

cover

Scales the image to cover the entire element. Some parts of the image may be cropped.

Cover

contain

Scales the image to fit completely inside the element. Empty space may remain.

Contain

Custom Size

background-size: 250px 120px;

Custom Size

5. Background Position

Controls where the background image is placed inside the element.

left center

Left Center

right center

Right Center

center top

Center Top

Custom Position: 80% 30%

Custom Position

6. Background Attachment

scroll

The background moves with the element as the page scrolls.

Scroll

fixed

The background is fixed relative to the viewport in browsers that support this behavior. It may behave differently on mobile.

Fixed

7. Linear Gradient

Creates a gradual color transition in a chosen direction.

Left to Right

Linear Gradient

Diagonal Gradient

Diagonal Gradient

Gradient Over an Image

Gradient Overlay

8. Radial Gradient

Creates a circular or elliptical gradient that spreads outward.

Radial Gradient

9. Conic Gradient

Transitions colors around a central point, similar to a color wheel.

Conic Gradient

10. Multiple Backgrounds

Multiple background layers can be applied to one element. The first image is painted on top of the following images.

Multiple Backgrounds

11. Background Clip

Controls how far the background painting extends.

border-box

Border Box

padding-box

Padding Box

content-box

Content Box

12. Background Origin

Controls the area used as the starting reference for positioning a background image.

border-box

Origin: Border Box

padding-box

Origin: Padding Box

content-box

Origin: Content Box

13. Background Blend Mode

Blends the background image with the background color.

Multiply Blend Mode

14. Background Shorthand

Multiple background settings can be combined into one declaration.

Background Shorthand
